## Data Analyst Internship
->Objective

The objective of this task is to design an interactive
business dashboard for business stakeholders using Tableau
and the Sales Superstore dataset.

->Tool Used

Tableau

->Dataset

Sales Superstore Dataset

->KPIs

- Total Sales
- Total Profit
- Total Orders
- Profit Margin

->Visualizations

- Monthly Sales Trend
- Sales by Category
- Profit by Category
- Sales by Region
- Sales by Segment
- Top 10 Products
- Sales vs Profit
- Discount vs Profit

->Interactive Features

- Year filter
- Region filter
- Category filter
- Segment filter
- Dashboard filter actions
- Interactive tooltips
- Dashboard navigation

->Deliverables

- Tableau Dashboard
- Dataset
- Dashboard Screenshots
- PPT Summary
- README

->Conclusion

The interactive Tableau dashboard provides an overview of
business sales and profitability and helps stakeholders
analyze trends, categories, regions, products and customer
segments for data-driven decision making.
